# Real-Time GenAI Customer Service Bot internship project

Project Overview

This project is a Real-Time GenAI Customer Service Bot designed to improve customer support by using AI-based features to understand customer messages, process information, manage support requests, and provide relevant responses.

The project was developed as a training and internship project by extending the same chatbot with multiple features across six tasks.

Project Objectives

Build a real-time AI-based customer service chatbot.
Improve the chatbot's knowledge management and response quality.
Process different types of customer information and files.
Manage unresolved customer conversations through support tickets.
Provide accurate and authorised information using a RAG-based knowledge assistant.
Analyse customer sentiment and support multiple languages.
Improve customer support through escalation, session management, and context handling.

Tasks Implemented

Task 1 – Knowledge Base Pipeline
Created a knowledge base update and monitoring pipeline with features such as document processing, duplicate detection, validation, version handling, access control, sensitive-data masking, maintenance-window checks, and retry handling.

Task 2 – Multimodal Customer Input
Extended the chatbot to process different customer inputs such as messages, images, invoices, PDFs, and screenshots using OCR and validation.

Task 3 – Support Ticket Workflow
Developed a workflow for converting unresolved conversations into structured support tickets with priority, SLA handling, routing, duplicate detection, and masked handoff information.

Task 4 – RAG Knowledge Assistant
Built a RAG-based knowledge assistant that uses product documents, FAQs, policies, and troubleshooting information with metadata, access control, policy handling, and source citations.

Task 5 – Multilingual Sentiment Analysis
Integrated sentiment analysis to identify customer emotions and urgency and support appropriate response handling and escalation.

Task 6 – Multilingual Conversation and Session Management
Extended the chatbot to support additional languages, mixed-language messages, conversation context, language switching, session management, and clarification for uncertain inputs.
